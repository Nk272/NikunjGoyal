THE PLAYGROUND — things I built to understand things

The math under the pixels,
made playable.

A working set of interactive demos and small engines — dynamic programming you can watch fill in, a query optimizer you can step through, GPUs explained by animation, the curves under every vector graphic. Built for my own understanding; kept because they might be useful to yours.

Reviewing locally? Each card opens a self-contained build. Web demos run by just opening index.html — no server, no build step. The systems projects (DB, cache, bin-packing) are Python folders with a README + demo.py. Nothing here is committed or published yet — that's your call in the morning.
